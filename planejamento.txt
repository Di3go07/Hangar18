--- Regras ---

1. Os usuários finais não terão conta, apenas os responsáveis por alimentar e manter o site necessitarão de login.
    1.1 Autor: pode apenas escrever artgio.
    1.2 Editor: pode editar o que está escrito no texto de cada artgio.
    1.3 Administrador: pode editar o texto, excluir artigos e adiconar contas.

2. Como o site é divido em cargos e o usuário final pode apenas ler a notícias, algumas páginas serão restritas dependendo do cargo do usuário.
    2.1 Redação: a página de escrever uma matéria pode ser acessada apenas por "autor"
    2.2 Registrar: a página de registrar um usuário só pode ser acessada por "administrador"
    2.3 Edição: a página de edição pode ser acessada por "editar" e "administrador"

3. A tabela Publications armazena dados gerais do artigo, como o seu título, tipo e autor. O conteúdo, por sua vez, será armazenado na tabela Nods, cujas instâncias representam elementos html. Por exemplo, as informações gerais do artigo estarão em Publications e teremos uma instância para seu primeiro paragráfo, para o segundo e para uma imagem armazenados em Nods. A renderiza correta dos respectivos nods se dá por meio da chave estrangeira do id do artigo em cada um dos elementos.

4. Ao escrever um artigo, o autor pode declarar Keywords que facilitarão na busca por temas na navegação do site. Toda vez que o autor escreve uma keyword, o código verifica se ela já existe e relaciona seu id com o id do artigo na tabela Keywords-Publications, caso seja uma palavra nova, cria uma nova instância na tabela keyword.

5. Ao definir um subtítulo, o código deverá, automaticamente, gerar uma slug para ela e definir essa valor em Publications. Uma slug consiste em retirar caracteres especiais do subtitulo e substituir o espaço entre eles por hífen (-).

--- Tabelas ---

''''
User 
''''
- id : int
- nome : string
- email : string
- _password: string
- cargo: Enum(administrador, aditor, autor)

''''''''''''
Publications
''''''''''''
- author : User.id
- date : Datetime
- edited: Datetime
- id : int
- slug : string
- subtitle : varchar(250)
- title : varchar(100)
- thumb : string
- type : Enum(noticia, materia, resenha)

''''
Nods
''''
- id : int
- position : int
- publicationID : Publications.id
- tag : Enum(p, h3, img)
- value : string
- alt : varchar(100)
- caption : varchar(150)

''''''''
Keywords
''''''''
- id : int
- value : string

''''''''''''''''''''
Keywords-Publication
''''''''''''''''''''
- pulicationID : Publications.id
- keywordID : Keywords.id

--- URLs ---

hanagr18/
    home/ - retorna para a home do site
    noticia/ - retorna para uma página com uma lista das últimas instâncias de Publications com type igual "noticia"
    noticia/{slug} - caso exista a slug, retorna a Publication com esse valor e os respectivos nods e keywords dela. Isto é, renderiza um artigo completo
    materia/ - retorna para uma página com uma lista das últimas instâncias de Publications com type igual "materia"
    materia/{slug} - caso exista a slug, retorna a Publication com esse valor e os respectivos nods e keywords dela. Isto é, renderiza um artigo completo
    resenha/ - retorna para uma página com uma lista das últimas instâncias de Publications com type igual "resenha"
    resenha/{slug} - caso exista a slug, retorna a Publication com esse valor e os respectivos nods e keywords dela. Isto é, renderiza um artigo completo
    login/ - renderiza a página de login
    registrar/ - renderiza a página de registrar um usuários. Restrito apenas aos administradores
    perfil/{nome} - caso exista o nome de usuário, retorna a sua página pessoal
    redacao/ - renderiza a página com o formulário para escrever um artigo. Restrito apenas aos autores.
    editar/{id} - caso existe o ID, abre um formulário com todos os dados de Publications e Nods do artigo renderizados para serem alterados e, após enviados, editarem a instância dela no banco de dados. Restrito aos editores.
